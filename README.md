### 🛡️ StoreGuard — 지능형 CCTV 기반 소상공인 보안 감지 시스템
> `Company Project` | 2026.07 ~ 2026.09

CCTV 이벤트·동선·장애를 감지·집계해 점주·운영자에게 대시보드·리포트·푸시로 제공하는 백엔드 API 서버 *(사내 프로젝트로 소스코드 비공개)*

- AES-GCM 암호화된 휴대폰 번호의 부분 일치 검색을 위해 **HMAC-SHA256 n-gram blind index** 구축 + 키 교체용 재암호화 러너 → 풀스캔 **337ms → 171µs**
- 비밀번호 변경 후에도 잔존하던 JWT AccessToken을 **계정 단위 컷오프 컬럼**(같은 트랜잭션, 조건부 update)으로 폐기 → 생존 창 **3,600초 → 0초**
- 다중 인스턴스 cache stampede를 **Redis 소유 토큰 락 + Lua compare-and-delete**로 해결 → 동시 요청 64건에 집계 **1회**, 락 오삭제 **20/20 → 0/20**
- FCM 알림 모듈을 유형 축·수단 축 **SPI 2축 구조**로 분리해 코어 수정 없이 확장, 주소 해석 배치화로 1,000건 기준 **약 51배 개선** → 사내 공용 라이브러리화
- `Spring Boot 4.1` `Java 17` `MySQL` `Redis` `FCM`

### 🎬 MOOV — 바이오리듬 기반 개인화 영화 추천 서비스
> `Capstone Project` 🏅 캡스톤 FAIR 장려상 | 2025.12 ~ 2026.03

[![GitHub](https://img.shields.io/badge/GitHub-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/LeeHyunWoo02)

TMDB 1990년~현재 영화를 자체 DB로 적재하고, 좋아요·바이오리듬(P, E, I) 신호를 TFRS 기반 AI 추천 서버(FastAPI)에 넘겨 개인화 추천을 제공하는 Android 플랫폼. 서버 API·배치·DB 설계·Docker 담당 (원천 400만 → 서비스 140만 → AI 학습 4만 건)

- LIKE 풀스캔(약 120만 행, **30초+**) 검색을 **MySQL n-gram MATCH…AGAINST** 풀텍스트로 전환 → **서브밀리초**, 관련도 정렬 개선
- 영화 1건씩 저장하던 적재를 **ItemStreamReader + NamedParameterJdbcTemplate 벌크 upsert**로 전환 → 저장 왕복을 청크(50)당 7회로 고정, retry·backoff·skip 내결함성 및 실패 지점 재시작
- `Spring Boot` `Spring Batch` `MySQL` `Docker` `FastAPI`
